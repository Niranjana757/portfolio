Mind Mate AI – Emotional Wellness Companion

Project Overview

Mind Mate AI is an AI-powered emotional wellness companion designed to support students by providing conversational assistance, mood tracking, and personalized wellness recommendations.

The system uses Generative AI concepts and retrieval-based techniques to deliver meaningful responses and create a supportive user experience.

Key Features

  • AI-powered conversational chatbot
  • Mood tracking functionality
  • Personalized wellness suggestions
  • Conversation memory using SQLite
  • Fast semantic search with FAISS
  • Generative AI response generation

Technologies Used

  • Python
  • Ollama
  • LangChain
  • SQLite
  • FAISS
  • Hugging Face Transformers

What I Learned

  • Building AI-based applications with Python
  • Working with Large Language Models locally using Ollama
  • Implementing LangChain workflows
  • Managing vector search and embeddings with FAISS
  • Integrating databases with AI applications
  • Designing user-focused conversational systems

Project Outcome

This project strengthened my understanding of Generative AI, prompt-based interaction, data retrieval techniques, and practical AI application development. It also improved my problem-solving, debugging, and system integration skills.
